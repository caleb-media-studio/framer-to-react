# Security

This tool processes design archives and can preserve executable React code. Treat external archives as untrusted input. Review the archive, source code and dependencies before building or running its generated application. Do not run unknown project code with credentials or sensitive filesystem access.

Report suspected vulnerabilities using GitHub's private vulnerability reporting if enabled. Otherwise request a private reporting channel through the repository maintainers without disclosing exploit details publicly.

Do not post access tokens, private project exports or confidential screenshots in issues.
